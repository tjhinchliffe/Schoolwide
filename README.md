## Install or update

**Windows:** if Schoolwide shows **Update Available**, open it to read what’s new. Choose **Install Now**, then **Restart and Install** when ready. A visible installation window shows progress while Schoolwide is closed. Keep your existing shortcuts, wait for installation to finish, then leave the Run option selected and choose **Finish** to reopen Schoolwide. If your current copy does not offer updates, download and run the Windows installer above.

**Apple Silicon Mac (M1 or newer):** quit Schoolwide, download the Mac file above, open it, then drag **MOSAIC Schoolwide** into **Applications** and replace the previous copy. Open Schoolwide from Applications. Choose **About This Mac** from the Apple menu if you are unsure which Mac you have.

The Mac download is not Apple-notarised. If macOS or your school computer asks for approval to open or install Schoolwide, contact your school IT support. [Apple’s help with opening downloaded apps](https://support.apple.com/en-au/102445) may also be useful.

## What’s new since 2027.0.1

- Explore English and Mathematics **Grade Distributions**, compare assessment bands, and save Grade Inquiries.
- Use **Investigate** to follow cohorts, compare measures and explore individual students.
- Read students’ results in the **Evidence Ledger** or **Student Journey**, with notes and RTI.
- Organise Dashboard layouts and Table column groups, then carry those views into offline HTML exports.
- Import PAT Testing, DIBELS 8 spreadsheets, PLD spelling, SAR attendance and more Learning Area Grade formats.
- Reuse shared spreadsheet layouts, import multiple files together and resolve student matches more easily.
- Prepare **Anecdotal Notes** templates and **Individual Student Reports** in Word or interactive HTML.
- Publish a single offline HTML report to a stable Shared Drive filename, with safe replacement and publication history.
- Work with larger collections using faster loading, smaller installers and updated searchable Help.

See the [full release notes](https://github.com/tjhinchliffe/Schoolwide/releases/tag/v2027.2.0) for all major updates and smaller improvements.

## Get started

Open **Configuration → School Profile** to set your school details, then **Student List** to load your current students. Choose **Import** to bring in assessment results. Use **Dashboard**, **Table** and **Students** to explore the results, and the **Help button or Search Help** in the top header for step-by-step instructions.

Everything needed to run Schoolwide is included. These downloads contain no school database, student list or personal settings. This repository provides public downloads; the application source remains private.

## About the Desktop Edition

One staff member maintains the school's master record on one computer, then shares read-only exports with authorised colleagues. Schoolwide is beta software and is not formally endorsed software by the Department of Education WA.
